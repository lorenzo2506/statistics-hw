Homework 5 – Riemann vs Lebesgue integration; numerical computation of the normal CDF

Exercise 1 – Riemann and Lebesgue integration

1.1 The two approaches

  • Riemann: partition the domain [a, b] into N equal subintervals of width h, pick a tag xi in each and add f(xi)·h. Here: midpoint tags and left tags.
  • Lebesgue: partition the range into K levels y0 < y1 < … and add yj·μ(Ej), where Ej = {x : yj ≤ f(x) < yj+1} is the preimage and μ its measure (length). This is the integral of the simple function s ≤ f that equals yj on Ej. Two versions: exact preimages (μ{f ≥ t} worked out analytically for each f) and sampled measure (f is sampled at M points, the values are sorted and μ{f ≥ t} is the fraction of samples ≥ t, like a real black-box program). For the unbounded 1/√x the levels are geometric (yj = ρj) up to 106.

1.4 Pathological functions

Dirichlet function (1 on the rationals, 0 on the irrationals, on [0, 1]). In every subinterval there are both rationals and irrationals, so for every partition the upper Darboux sum is 1 and the lower one is 0: the gap never closes and the function is not Riemann integrable (Riemann sums give 1 or 0 depending on the tags). Note that a computer cannot even evaluate it: every floating-point number is a rational. Lebesgue: the preimage of the value 1 is ℚ ∩ [0,1], which is countable; the first rationals can be covered by intervals of lengths ε/2n, with total length ≤ ε for every ε, so μ(ℚ ∩ [0,1]) = 0 and the integral is 1·0 + 0·1 = 0.

Thomae’s function (1/q at p/q in lowest terms, 0 at irrationals). It is continuous at the irrationals and discontinuous at the rationals, and it is Riemann integrable with integral 0: the lower sums are always 0 and the upper sums, computed exactly below (the sup on a subinterval is 1/q for the smallest denominator q of a fraction inside it), tend to 0, but slowly. Lebesgue: for each level 1/k the preimage {f ≥ 1/k} is a finite set of fractions with q ≤ k (Farey sequence), so it has measure 0 and the integral is 0. Both approaches agree.

1.5 Discussion

Same value. For every Riemann-integrable function in the list the two approaches converge to the same number: a Riemann-integrable function is Lebesgue integrable with the same integral.

Accuracy and convergence. For smooth functions the midpoint sum is by far the best (error ∝ 1/N², e.g. about 10−7 for x² at N = 1000), while the Lebesgue sum with K levels has error ∝ 1/K (about 5·10−4): the simple function rounds f down to a level, so the error is about the level width times the length of the domain. At a jump the Riemann sums lose accuracy (O(1/N), unless the jump is on a grid point), whereas the Lebesgue sums are unaffected by where the jump is, since only the values taken and the measures of the preimages matter. For the unbounded 1/√x the left sum is infinite at x = 0, the midpoint sum converges slowly (error ∝ N−1/2) and the Lebesgue sum with geometric levels converges like 1/K (see the table): partitioning the range handles the singularity naturally.

Efficiency. Riemann costs N evaluations of f and no memory. The Lebesgue method with exact preimages costs only K cheap evaluations of μ{f ≥ t}, but it needs an analytic description of the preimages, which is rarely available. With the measure estimated from M samples it needs M evaluations of f plus a sort, O(M log M), and in practice it reduces to a Riemann-type sum whose values are rounded to the levels: it is not more accurate, only slower. The strength of the Lebesgue definition is theoretical (more functions are integrable, limits and integrals can be exchanged), not numerical.

Where they differ. Dirichlet (Lebesgue integrable, not Riemann integrable) and the unbounded 1/√x (an improper Riemann integral, a plain Lebesgue integral). Thomae shows that a function with a dense set of discontinuities can still be Riemann integrable.

Exercise 2 – Numerical computation of the standard normal CDF

Φ(x) = ∫−∞x (2π)−1/2 e−t²/2 dt. By symmetry, Φ(−x) = 1 − Φ(x) and Φ(0) = ½, so it is enough to integrate the density on [0, |x|] (see the Hogg–McKean–Craig notes, section 3.4).

2.1 The methods

  • Numerical integration of the density: composite trapezoidal rule (error ∝ h²) and Simpson’s rule (error ∝ h⁴).
  • Power series (from the notes): Φ(x) = ½ + (2π)−1/2 Σ (−1)k x2k+1 / (2k k! (2k+1)). It is alternating, so for large |x| huge terms cancel. A variant with only positive terms: Φ(x) = ½ + φ(x) Σ x2k+1 / (1·3·5···(2k+1)).
  • Through erf: Φ(x) = ½ (1 + erf(x/√2)). With the Abramowitz–Stegun 7.1.26 rational approximation (error < 1.5·10−7), or with erf computed by its series for small arguments and by a continued fraction of erfc for the tail (P(Z > x) = ½ erfc(x/√2), computed directly to avoid the cancellation in 1 − Φ).

2.7 Why no elementary formula? Liouville’s theorem

Statement used. “Elementary” functions are those built with finitely many rational operations, exp, log and algebraic functions. Liouville (1830s; in modern form Rosenlicht 1972, the reference quoted in the notes) showed: if f and g are rational functions and ∫ f·eg dx is elementary, then it equals h·eg for some rational function h, that is, h′ + g′h = f.

Application. For e−t²/2 take f = 1 and g = −t²/2, so we would need a rational h with h′ − t·h = 1. If h had a pole of order n at some point, h′ would have a pole of order n+1 and t·h one of order n, which cannot cancel: so h is a polynomial. But if h is a polynomial of degree d ≥ 0, t·h has degree d+1 ≥ 1 while h′ has degree d−1, so h′ − t·h has degree d+1 ≥ 1 and cannot be the constant 1 (and h = 0 gives 0 ≠ 1). Hence there is no elementary antiderivative. The same argument works for e−t². The antiderivative exists (the integral of a continuous function) and has the power series above, but it is not an elementary function.

The error function. One simply gives the new function a name: erf(z) = (2/√π) ∫0z e−t² dt, a special function. Then Φ(x) = ½(1 + erf(x/√2)) is an exact analytic representation, and 2Φ(1) − 1 = erf(1/√2) (68–95–99.7 rule). But this is only a change of name: erf is still defined by an integral or a series, so to get a number for a given x we need numerical methods anyway: series for small arguments, continued fractions or asymptotic expansions for the tails, and rational minimax approximations (Cody, Abramowitz–Stegun) like those used in numerical libraries. In practice one chooses by range of x and by the accuracy needed, and the tail is computed with erfc directly to avoid cancellation (the table shows that 1 − Φ would lose all its relative accuracy at x = 5).
